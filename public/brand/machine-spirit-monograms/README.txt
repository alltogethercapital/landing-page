MACHINE SPIRIT — 100 MS MONOGRAMS

100 original geometric MS constructions across 10 design directions.
The industrial weight and geometry were inspired by Atomic Machines.
These designs use original paths; they do not reproduce the reference mark.

Serve this folder with a local static server and open index.html to compare
all 100 logos, filter directions, switch light/dark, preview website sizes and
lockups, and save a personal shortlist. The gallery uses local JavaScript
modules, including Morphicons 1.7.1 (MIT license in vendor/morphicons/LICENSE).

svg/    100 scalable SVGs with genuinely transparent backgrounds.
png/    100 ink and 100 white transparent PNGs, each 1024 x 1024.
The contact sheets show every design with its three-digit number.
catalog.json maps each number to its design name and direction.

SVG colors use currentColor for inline website use. SVGs displayed as an
image default to black. White and ink PNG versions are ready for direct use.
The artboards include clear space around each mark.

Studio picks: 002 Vector, 018 Crosslink, 031 Totem, 053 Current, 088 Octant.
The gallery lives at /machine-spirit/logos in the website project.
For a local standalone preview, serve the public folder with a local server.

These are identity exploration options. Pick a number to refine and apply
as the website's final logo.
