# Machine Spirit logo exploration

One hundred monochrome wing-mark directions, organized as ten families with ten refinements each.

- Open `index.html` to cycle through every option.
- `machine-spirit-100-overview.svg` is the full contact sheet.
- Every option in `svg/` is resolution-independent and has a transparent background.
- All displayed wordmarks use **Machine Spirit** only.

## Families

1. **Core Wing** — Closest to the existing mark, with a softer engineered finish.
2. **Signal Wing** — A lighter, broadcast-like rhythm with five signal feathers.
3. **Spirit Core** — A stronger central presence held inside the wing structure.
4. **Ascendant** — Longer upper planes and a more upward, forward posture.
5. **Forge Wing** — Fewer, heavier forms with a compact industrial stance.
6. **Aerial** — Slim, widely spaced planes with an almost weightless profile.
7. **Relay** — A technical cadence that reads as wing, signal, and transfer.
8. **Veil Wing** — More organic corner behavior without losing the hard geometry.
9. **Talon** — Sharper taper and shorter lower forms for a decisive silhouette.
10. **Synthesis** — The wing and machine-signal readings brought into one balanced form.
