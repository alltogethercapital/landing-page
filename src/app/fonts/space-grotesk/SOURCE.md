- Font: https://github.com/google/fonts/blob/00a38a53f92aef923b9353f40128e8f4552ddae4/ofl/spacegrotesk/SpaceGrotesk%5Bwght%5D.ttf
- License: https://github.com/google/fonts/blob/00a38a53f92aef923b9353f40128e8f4552ddae4/ofl/spacegrotesk/OFL.txt

The bundled `SpaceGrotesk-Variable.ttf` is the unmodified official variable font, with a weight axis from 300 to 700.

The standalone gallery uses the same variable font from `public/fonts/SpaceGrotesk-Variable.ttf`.
`public/fonts/SpaceGrotesk-Regular.ttf` is its static weight-400 instance, derived with FontTools 4.66.1 for the Open Graph image renderer. The font retains the SIL Open Font License supplied in `public/fonts/SPACE-GROTESK-OFL.txt`.
